[[introduction]]
== Introduction

In this hands-on lab, you'll tackle the real-world challenge of deploying, managing, and securing a modern application platform on OpenShift Container Platform 5. You'll unify your infrastructure by placing virtual machines, containers, and applications on the right clusters -- first on your own, or with Red Hat OpenShift Lightspeed if you'd prefer a more hands-off approach.

You'll also explore the new agentic features in OpenShift, using them to craft dashboards, fix broken workloads, and triage alerts while improving the security posture of your OpenShift 5 environment. With your applications up and running, the focus shifts to sovereignty and security on OCP 5. You'll use Red Hat Advanced Cluster Security (RHACS) to scan for vulnerabilities, visualize network and runtime behavior, and create guardrails that limit each workload's attack surface. Next, you'll implement multi-factor, keyless workload authentication with Red Hat Zero Trust Workload Identity Manager (ZTWIM), ensuring containers, virtual machines, and AI applications have the right access to systems and data.

By the end of the lab, you'll have a practical blueprint for management and security on OCP 5 in the age of agentic AI -- using RHACM, RHACS, and ZTWIM to address the operational and security challenges of distributed, cloud-native AI workloads at scale.

[[what-youll-learn]]
== What You'll Learn

The modules follow that path. Through hands-on activities, you will:

* Place virtual machines and a new cluster on the fleet yourself with Red Hat Advanced Cluster Management (RHACM)
* Run an AI workload on Red Hat OpenShift AI, on the cluster where the data already lives
* Place an application on the right clusters with OpenShift GitOps
* Use RHACS to scan for vulnerabilities, watch runtime behavior, and enforce guardrails that limit the attack surface
* Apply sovereignty policies so regional workloads stay in bounds
* Build and sign a container image so the supply chain stays under your control

[[getting-started]]
== Getting Started

This lab has two OpenShift clusters pre-configured. One cluster called *local-cluster* and another cluster in AWS labelled *aws-us*. 

The environment has also already been pre-configured for you with the following applications already deployed:

* On the right there are five tabs:
** *OpenShift Console*: this is where you will spend the majority of the time configuring the various environments and applications
** *Advanced Cluster Security*: the console for OpenShiftsecurity related activities.
** *Quay*: the console for image registry and artifacts
** *OpenShift AI*: the console for building and training AI models via Jupyter notebooks and specialized accelerators
** *Terminal*: command line access to the OpenShift environment. You will run commands in this tab to deploy a few initial settings and interact with the applications.
