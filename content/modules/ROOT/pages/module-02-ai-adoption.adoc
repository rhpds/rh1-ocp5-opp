This module is the OpenShift 5 First Look path for the agentic features. Work through the three exercises in order.

* xref:module-02-agentic-troubleshooting.adoc[Agentic Troubleshooting] — Automated root-cause analysis and remediation of application issues triggered by alerts
* xref:module-02-mcp-server.adoc[MCP Server] — Model Context Protocol servers for OpenShift and ACS, enabling AI agents to interact with cluster and security APIs
* xref:module-02-mcp-gateway.adoc[MCP Gateway] — Part of Red Hat Connectivity Link, providing federated MCP access, team isolation, authentication, and policy enforcement
